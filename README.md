## Whisper Base Model — v1.0.0

Bản phát hành cung cấp mô hình Whisper Base (`ggml-base.bin`) phục vụ chức năng nhận dạng giọng nói trong hệ thống AVA Service.

### Hướng dẫn cài đặt

1. Tải file `ggml-base.bin` tại mục **Assets** bên dưới.
2. Mở thư mục dự án trên máy tính.
3. Truy cập `ava_service/models/whisper/`.
4. Sao chép file `ggml-base.bin` vào thư mục trên.
5. Kiểm tra cấu hình AVA Service để bảo đảm đường dẫn mô hình chính xác.
